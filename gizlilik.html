Gizlilik Politikası

"Kisaca Nedir Yukleyici" uygulaması yalnızca Kısaca Nedir? kanalının sahibi tarafından, kendi hazırladığı videoları kendi YouTube kanalına yüklemek için kullanılır.

Uygulama YouTube API Hizmetleri'ni kullanır ve yalnızca video yükleme izni (youtube.upload) ister. Başka hiçbir kullanıcı verisi toplanmaz, saklanmaz, paylaşılmaz veya satılmaz.

YouTube Hizmet Şartları: youtube.com/t/terms · Google Gizlilik Politikası: policies.google.com/privacy

YouTube API Hizmetleri

Bu uygulama YouTube API Hizmetlerini kullanır. Uygulamayı kullanarak YouTube Hizmet Şartları'nı kabul etmiş olursunuz. Google'ın verileri nasıl işlediği için: Google Gizlilik Politikası.

Veri saklama ve silme

Uygulama hiçbir kullanıcı verisini saklamaz. Yalnızca yükleme için gereken erişim anahtarı, kanal sahibinin şifrelenmiş GitHub gizli değişkenlerinde tutulur. Silme talebi için kadir.yt25@gmail.com adresine yazabilir veya erişimi aşağıdaki bağlantıdan hemen kaldırabilirsiniz; erişim kaldırıldığında anahtar geçersiz olur ve 7 gün içinde sistemden silinir.

Verilen erişim izni istenildiği zaman Google hesap izinleri sayfasından geri alınabilir.
